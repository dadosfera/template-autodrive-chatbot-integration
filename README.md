# Template de Repositório

Este é um template básico para qualquer software da Dadosfera. Use este repositório como ponto de partida para novos projetos.

## Conteúdo

Este template inclui:

- Arquivos de configuração básicos
- Estrutura de diretórios recomendada
- Licença padrão
- Configurações de CI/CD
- Guias de contribuição

## Como usar

1. Clone este repositório ou utilize-o como template ao criar um novo repositório
2. Personalize os arquivos de acordo com as necessidades do seu projeto
3. Atualize este README com informações específicas do seu projeto

## Estrutura de diretórios

```
.
├── .github/             # Configurações do GitHub (workflows, templates)
├── docs/                # Documentação
├── src/                 # Código-fonte
├── tests/               # Testes
├── .gitignore           # Padrões para ignorar no Git
├── LICENSE              # Licença do projeto
├── README.md            # Este arquivo
└── CONTRIBUTING.md      # Guia de contribuição
```
